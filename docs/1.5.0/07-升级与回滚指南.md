# CCB v1.5.0 升级与回滚指南

## 1. 升级前

1. 完全退出 CCB，确认托盘图标消失。
2. 备份用户目录中的 `.ccb`，尤其是 `.ccb/claude-configs`、`.ccb/backup`、`.ccb/registry` 与 `settings.json`。
3. 记录当前 CCB 版本、Claude Code 版本和正在使用的 provider/config。
4. v1.5.0 不移动 `.ccb/claude-configs`，不要手工创建或迁移到 `.ccb/workspaces/claude-code`。

## 2. 应用升级

- Installer 用户：关闭旧版本后运行 `CCB-Setup-1.5.0.exe`，保留原安装目录即可。
- Portable 用户：解压或运行新的 `CCB-Portable-1.5.0.exe`；不要覆盖唯一一份旧 binary，先保留可回退副本。
- Zip 用户：解压到新目录，不与旧版本文件混合。

首次启动后检查 About version、现有 Claude 配置列表、Managed Mode 状态和 Settings 中的 artifact-specific templates。旧 global template 若曾被用户修改，会迁移为 `claude-code/user-settings` override；内置默认值不会被误判为 override。

## 3. Registry 更新

- 应用只自动检查 manifest，不自动下载完整 bundle。
- 用户确认安装后依次执行 Ed25519 signature、SHA-256、size、UTF-8、schema、版本兼容和 downgrade 校验。
- 用户 template override 优先于 registry template；registry update/rollback 不覆盖本地 override。
- Production remote registry 在正式 publisher public key 注入前保持 fail-closed preview。

## 4. 回滚

### 回滚应用 binary

1. 完全退出 v1.5.0。
2. 使用保留的旧 installer/portable/zip binary 恢复应用。
3. 不删除 `.ccb`，不手工降级配置内容。
4. 启动旧版后核对配置列表、激活配置和 Managed Mode；若旧版无法理解新设置字段，它应忽略未知字段，不能删除整个 settings file。

### 回滚 registry

在 Settings/About 使用 registry rollback，仅恢复 last-known-good JSON bundle。该操作不会执行脚本、迁移用户文件或删除 template override。

### 恢复用户数据

只有出现真实数据损坏时才恢复升级前 `.ccb` backup。恢复前先保留故障现场副本；不要在应用运行期间覆盖目录。

## 5. 诊断证据

反馈升级问题时附带：应用版本、Windows 版本、安装形态、复现步骤、相关日志、`.ccb` 目录结构（不要包含 token/secret 内容）以及是否执行过 registry update/rollback。
