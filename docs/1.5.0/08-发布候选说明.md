# CCB v1.5.0 Release Candidate Notes

## 核心变化

- 从 Claude Code 专用逻辑演进为 declarative JSON registry 驱动的多 AI Agent 配置管理基础。
- 内置 Claude Code 完整兼容 adapter 与 Codex CLI read-only adapter。
- 支持受控 detection、artifact discovery/read、format validation、atomic edit、backup/restore 和 bounded retention。
- 新增 artifact-specific template ownership：`USER_OVERRIDE > REGISTRY > EMBEDDED`，支持来源显示、独立覆盖、移除恢复与逐行 diff。
- Remote registry 增加 Ed25519 raw-byte signature、SHA-256、size、fatal UTF-8、schema、app compatibility、downgrade protection 和 last-known-good rollback。
- Renderer 首屏非关键任务改为 idle batches；StatisticsService 与 app quit lifecycle 竞态已修正。
- Claude legacy workspace path 集中到 compatibility facade，v1.5.0 不移动用户数据。

## 安全边界

- Remote registry 不能携带 JavaScript、shell、WASM、native plugin 或 arbitrary executable arguments。
- Renderer 不能扩展 filesystem roots、下载 URL、hash、public key 或 handler allowlist。
- Electron renderer 启用 context isolation、sandbox、nodeIntegration false、webSecurity，并拒绝新窗口和跨 document navigation。
- Production publisher public key 未注入前 remote registry 维持 preview；这是 release preflight 的显式 blocker。

## 已知需人工验收

- Windows Installer/Portable/Zip 的实际安装、首次启动、卸载与快捷方式。
- 真实 Claude 配置 scan/edit/activate/backup、MCP、Agent、Skill 与 Managed Mode。
- Artifact template UI、legacy custom template migration 和 registry update/rollback 交互。
- Cold start、idle/tray memory、CPU、watcher 与 scan telemetry 三轮 median。

## 不在 v1.5.0 范围

- Public marketplace、账号、云同步、remote executable plugin。
- Codex TOML edit/validation；可信 TOML codec 落地前保持 read-only。
- `.ccb/claude-configs` 到 future workspace 的物理迁移。
